Recording cards — speaker s08

28 cards, 33 clips, about 13 minutes

Thank you for helping! You'll play a customer calling a loan company's phone helpline. Each card describes a situation. For each one, record yourself saying what you'd actually say.

  • Don't read the card out loud. Say it the way you'd naturally talk on a phone call.
  • Use whatever language feels natural: Hindi, English, Hinglish or a mix. Short or long is fine.
  • Use your phone's voice recorder. One clip per card (or per turn). Keep each clip under 25 seconds.
  • Record somewhere normal: a quiet room is good, a bit of background noise is fine too.
  • Name each file exactly as shown in blue, e.g. s08_S02. Keep the phone's file type (.m4a is fine).
  • Conversations: record each turn as a separate clip. Between turns, read the agent's reply on the card (in grey), then record what you'd say back to it.
  • The names, loans and numbers are made up. Never say your real details.
  • Today is 13 October 2026.

When you're done, send all the files back (Google Drive, WhatsApp as documents, or AirDrop). The recordings are only used to test a voice agent for a portfolio project.
